Propositions Presented in Stephen Yablo's Aboutness

This is the comprehensive list of propositions as presented in Stephen Yablo(2014)'s Aboutness. Numbers in parentheses indicate page numbers.

Notation

  • Italic: sentences (A, B, C, ...) or worlds (w, w', ...)
  • Bold: subject matter (a is the subject matter of A.)

Propositions

  1. A hypothesis is partly true iff it has parts that are wholly true. (11)
  2. One hypothesis is part of another iff it is implied by the other. (11)
  3. B is part of A iff the inference from A to B is
    1. truth-preserving — A implies B
    2. aboutness-preserving — A's subject matter includes that of B. (15)
  4. m1 = m2 iff worlds differing where the first is concerned differ also with respect to the second, and vice versa. (27)
  5. n is part of m iff
    1. each n-cell includes an m-cell,
    2. each m-cell is included in an n-cell. (30)
  6. A is true about m in w iff A is true simpliciter in a world m-equivalent to w. (32)
  7. S is wholly about m iff S's truth-value supervenes on m, that is, S always evaluates the same in m-equivalent worlds. (38)
  8. S cannot be differently true in two worlds, unless things have changed where its subject matter is concerned. (41)
  9. Something has changed, between one world and another, where S's subject matter is concerned, only if S is differently true in the two worlds. (41)
  10. The subject matter of S = the relation m such that worlds are m-dissimilar iff S is differently true in them. (41)
  11. B is part of A just if the argument A, so B is
    1. truth-preserving — A implies B; A's information value includes the information value of B
    2. aboutness-preserving — A's subject matter (anti-matter) includes the subject matter (anti-matter) of B
  12. B is part of A if and only if
    1. A implies B
    2. how B is true cannot change without changes in how A is true
    3. how B is false cannot change without changes in how A is false
  13. B is part of A if and only if
    1. A implies B
    2. each B↑ is implied by an A↑
    3. each B↓ is implied by an A↓
  14. Upward difference transmission: y is part of x only if y cannot change (in specified respects) while x remains the same (in those respects).
  15. The directed proposition that A consists of
    1. |A| = A = A's truth-conditional content, and
    2. <A> = a = A's subject matter
  16. The directed proposition that Am — consisting of
    1. |Am| = Am's truth-conditional content, and
    2. <Am> = Am's subject matter
  17. X/≡ is the result of expanding X to include everything equivalent to any of its members. (50)
  18. |Am| = |A|/m = the set of worlds where A is true about m. (50)
